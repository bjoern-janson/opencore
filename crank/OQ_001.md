## Frozen question

Can two quantum acquisition histories produce the same first classical evidence while leaving different future corrective possibilities, such that collapsing the histories into one coarse event carrier causes a measurable downstream failure?

## Frozen setup

Initial state:

```text
rho0 = |+><+|
```

Instrument A is ordinary Z measurement:

```text
A0 = |0><0|
A1 = |1><1|
```

Instrument B has the same Z-outcome POVM but prepares `|+>` after either outcome:

```text
B0 = |+><0|
B1 = |+><1|
```

Both are valid instruments because their Kraus completeness sums equal identity. More strongly:

```text
A0†A0 = B0†B0 = |0><0|
A1†A1 = B1†B1 = |1><1|
```

Therefore the first-outcome distributions are identical for every input density operator, not merely for the chosen `|+>` specimen.

Condition on the same realized first outcome `x=0`.

Coarse carrier:

```text
C_coarse(A,0) = (Z,0)
C_coarse(B,0) = (Z,0)
```

Post-measurement states differ:

```text
A -> |0><0|
B -> |+><+|
```

## Prospective discriminator

Second measurement: X basis.

Exact result:

```text
P_A(X+ | x=0) = 1/2
P_B(X+ | x=0) = 1
TV distance         = 1/2
```

Thus the same coarse carrier corresponds to two incompatible future outcome distributions.

Any predictor keyed only by `(Z,0)` must emit one value for `P(X+)`. Under equal worst-case treatment of the two histories, the minimax value is `3/4`, leaving irreducible total-variation error `1/4` in either history.

## Negative control

Second measurement: Y basis.

Exact result:

```text
P_A(Y+ | x=0) = 1/2
P_B(Y+ | x=0) = 1/2
TV distance         = 0
```

So the apparatus distinction does **not** make every future probe differ. It becomes consequential only for a discriminating measurement.
