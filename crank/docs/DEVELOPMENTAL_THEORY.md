## 1. Canonical causal loop

The current mechanistic core is:

```text
E_t
-> Pi_t
-> pi_t
-> A_t
-> O_{t+1}
-> W_{t+1}
-> E_{t+1}
```

with external world state:

```text
O_{t+1} = g(X_t, A_t, epsilon_{t+1})
```

where:

```text
E_t      persistent epistemic state / accumulated leverage
Pi_t     effective representation / interface
pi_t     policy induced by that state
A_t      selected action / intervention
O_t+1    externally generated observation / consequence
W_t+1    recognition / warrant judgment
E_t+1    revised persistent state
```

The strongest causal distinction is:

```text
exogenous outcome generation
!=
exogenous outcome exposure
```

Persistent state need not control what reality returns after a fixed intervention. It can still control which intervention is selected and therefore which observations enter the system's future history.

This mechanism is called:

```text
endogenous evidence acquisition
```

The property under study is:

```text
non-collapsible corrective exposure
```

Compactly:

> **External truth can remain independent while exposure to it becomes endogenous.**

## 2. Why external evidence is not enough

An observation may be generated entirely by an external world while its acquisition remains endogenous.

If:

```text
E_t -> Pi_t -> pi_t -> A_t
```

then changing persistent state can change the distribution of actions. Since observations depend on actions, the encountered observation distribution changes even when the environment's response mechanism is unchanged.

The systems-level danger is therefore not only fabrication or direct manipulation of evidence.

It is:

```text
current persistent state
-> future sampling policy
-> absence / delay of observations that could reduce that state
```

This allows self-confirming trajectories without requiring an explicit self-preservation objective.

## 3. Six-gate correction chain

Correction is now decomposed as:

```text
C1  physical availability
C2  policy support
C3  actual selection
C4  discrimination
C5  recognition
C6  persistent authority revision
```

`C4` splits into:

```text
C4a  environmental discrimination
C4b  representation-preserved discrimination
```

A path can fail independently at each layer.

Examples:

```text
C1=1, C2=0
    corrective action exists but is policy-excluded

C2=1, C3 approximately 0
    technically supported but behaviorally negligible

C3=1, C4a=0
    action occurs but reality does not distinguish alternatives

C4a=1, C4b=0
    world distinguishes but interface aliases the observations

C4b=1, C5=0
    distinction arrives but is assigned the wrong epistemic role

C5=1, C6=0
    recognized evidence arrives but persistent authority does not change
```

This is why `the corrective action exists` is not a sufficient corrigibility test.

## 10. Developmental claim

The current systems-level hypothesis remains:

> **Intelligence develops by constructing increasingly useful ways for reality to correct what currently governs it.**

But the causal mechanism is now more specific.

A useful persistent system must not only retain information and authority-update paths. It must preserve enough causal exposure that future external consequence can still reach the structures that govern behavior.

The current central question is:

> **How can persistent epistemic state gain useful causal leverage over behavior without gaining enough leverage over evidence acquisition to suppress, delay, or extinguish the exposure required to reduce that leverage?**

## 11. L1 / L2 / L3 frontier

The challenge problem is now separated into:

```text
L1  challenge preservation given D_t^oracle
L2  diagnosis that D_t^agent is insufficient
L3  construction of a better challenge set
```

PCE-001 supports only L1 under an externally supplied challenge set.

It does not test:

```text
D_t^agent =? D_t^oracle
```

L2 is not a weak form of L3.

A system could correctly infer:

```text
my challenge set is inadequate
```

without being able to produce a missing challenge that repairs it.

The next frontier is therefore:

> **Can an adaptive system detect that its current corrective-exposure topology is inadequate without being told which missing intervention would repair it?**

No L2 mechanism is frozen or implied here.
