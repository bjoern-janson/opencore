# Claim Boundaries and Current Status

## 1. Why this document exists

OpenCore deliberately separates:

```text
observed result
candidate interpretation
systems-level hypothesis
future target
architectural metaphor
```

This page keeps those authority levels explicit.

### Base-001

Supported on the constructed 12-unit shared-world family:

- one warranted global standing reached all local projectors;
- persistent response occurred only in externally designated relevant units;
- one upstream warrant revocation removed all tested warrant-dependent effective consequences;
- unrelated post-event local learning survived;
- no local destructive cleanup was required;
- an unlicensed local-to-global promotion was blocked while a matched licensed export was admitted.

### Base-002A

Supported on the target-bound constructed reopening path:

```text
ADMIT(G) != REOPEN(G) != REPLACE(G, G')
```

A counterexample-backed reopen transition withdrew current authority from `G` and dependent projections without acquiring successor-install authority. Later separately warranted evidence could install `G'`.

### Base-002B negative result

Supported as a failure of Nano V0's current contract representation:

> an ordinary precondition used only as a natural execution guard is automatically promoted into continuing warrant ancestry, causing strict reopening to self-invalidate when the guarded incumbent is revoked.

The forced distinction is:

```text
execution guard != warrant dependency
```

No repair representation is established.

## 3. Candidate common interpretations

These have explanatory support but are not established universal laws.

### Lawful adaptive transition

Candidate:

> an adaptive transition should neither erase correction-relevant distinctions nor manufacture authority not warranted upstream.

### Premature quotient / unauthorized refinement

Candidate dual failure family:

```text
premature quotient
unauthorized refinement
```

### Reliable generalization as warranted invariance

Candidate target:

```text
reliable generalization = discovery and governance of warranted invariance
```

### Authority-filtered current world

The Nano ablation and Base experiments motivate:

```text
raw persistent state
!=
authority-effective current state
```

A standing may remain historically present while no longer participating in current authority because its warrant ancestry is dead.

This is supported mechanically in the tested family; its general architectural use remains a hypothesis.

## 4. Systems-level hypothesis freeze

The current developmental compression is:

```text
Reality
-> challenge / apparatus
-> consequence
-> organism interpretation
-> candidate transition
-> persistent authority
```

with:

```text
reality != measurement != interpretation != authority
```

The central hypothesis is:

> **Intelligence develops by constructing increasingly useful ways for reality to correct what currently governs it.**

The prospective developmental frontier is:

```text
live alternatives
+
discriminable challenge
+
recoverable consequence
+
live authority-update path
```

And the agency/authority split is:

> **The organism chooses where to risk being wrong.**
>
> **The persistence world constrains what the resulting consequence is allowed to change.**

These are systems-level hypotheses and explanatory compressions, not yet demonstrated general mechanisms.

## 5. Mental models and useful names

### Tiny computational world / mini planet

Useful architecture analogy:

```text
Nano = persistence-world transition rules
Mini = adaptive organism
Base = shared effective world + local adaptive processes
```

Base-001 makes one small part executable, but does not establish a general computational-world architecture.

### Authority firewall

Useful operational description of Nano's current role:

> a boundary between adaptive proposal and persistent state that can reject effects exceeding supplied contracts.

Nano is not a firewall against false beliefs or bad reasoning.

### Warrant-mediated world plasticity

Useful hypothesis motivated by Base-001:

> shared warranted structure can alter many local projections while remaining attributable and revocable through live warrant ancestry.

The general scaling claim remains open.

## 8. Current research posture

The working standard remains:

> preserve access to interesting hypotheses without granting them authority they have not earned.

The current theory is deliberately stopped at a coherent systems-level compression. The next advancement should be empirical: construct a failure or discrimination that forces revision.
