## 5. Candidate interpretations — not universal laws

### Bounded epistemic compounding

Candidate research object:

> Useful persistent state should be allowed to gain causal leverage without consuming the causal routes by which external consequence can reduce that leverage.

### Informational / topological / authority reopenability

Useful decomposition:

```text

!=

!=

```

### Temporal corrective exposure

BLITZCRANK-002 and PCE-001 motivate separating:

```text

```

No single scalar corrigibility metric is currently established.

### Premature quotient / unauthorized refinement

Still useful for many representation/authority wounds:

```text
premature quotient
unauthorized refinement
```

But PCE-001/FOREIGN-007 show this pair is not currently sufficient as a universal failure taxonomy. A system can preserve the relevant discriminator and avoid unearned authority while still suppressing the policy route needed to encounter correction.

### Authority-filtered current world

Mechanically supported on Nano/Base families:

```text
raw persistent state
!=
authority-effective current state
```

Its general architectural role remains a hypothesis.

## 9. Current research posture

The working rule is:

> Preserve access to interesting hypotheses without granting them authority they have not earned.

After PCE-001, the explicit contradiction-handling rule is:

```text
failed prospective prediction
-> mechanism loses authority

successful intervention
-> mechanism gains bounded authority only on identified dimensions
```

The next conceptual update should come from a frozen L2 discrimination, not from pre-solving L2 architecturally.
