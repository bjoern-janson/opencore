# Experimental Lineage

## Status

This is a map of the crank-science sequence. It is not the formal E001 execution record and does not amend K0.

The lineage is intentionally a mixture of positive and negative results. A failure is retained when it identifies a causal distinction that later experiments depend on.

## 1. Mini 001 — learn, persist, reopen, revise

Mini first demonstrated a tiny adaptive loop over affine rules in two scopes:

```text
experience -> unique candidate -> commit -> persist -> reload -> reuse
                                      |
                                counterevidence
                                      v
                                reopen / revise
```

A first 1,000-seed sweep exposed 79 failures because old and new affine rules can cross at one `x`. One post-change observation can therefore establish that an incumbent is wrong without identifying the replacement.

Minimal repair: request another probe when the replacement remains underdetermined.

Result after repair:

```text
10,000 pass / 0 fail
```

Earned distinction:

```text
I know my incumbent is wrong != I know what replaces it
```

## 2. Interface ladder / Mini 002 — representation vs missing information

The interface ladder separated four conditions:

```text
transparent   10,000 / 10,000 pass
opaque        10,000 / 10,000 pass
permuted           0 / 10,000 pass
aliased            0 / 10,000 pass
```

Interpretation:

- stable opacity is harmless when identity is preserved;
- arbitrary bijective coordinates can preserve information while breaking Mini's computational geometry;
- aliasing can destroy target-relevant identifiability.

Core distinction:

```text
representation failure != missing-information failure
```

A finite-history attack then showed that a representation can look sufficient because challenge coverage has not reached the hidden alias.

Earned distinction:

```text
no contradiction observed != no contradiction exists
```

## 3. Mini 003 — support is not closure permission

Paired worlds were constructed with identical finite history but different hidden reality:

- globally sufficient;
- hidden coverage defect;
- hidden representation defect.

At the initial STOP decision, the history did not identify which world obtained.

With an externally declared challenge adversary and residual-risk tolerance, closure became a separate decision from model support.

Earned distinction:

```text
model support != closure permission
```

## 4. Mini 004 — contract-scoped budgeted closure

Mini 004 introduced an external closure contract:

```text
p_min = 0.25
delta = 0.10
```

with a conservative miss bound:

```text
R(q) <= (1 - p_min)^q
```

The first licensed challenge count is `q=9`.

Important results:

```text
B=8 -> DEFER
B=9 -> STOP may become authorized
```

Closure is therefore:

> contract-scoped permission to stop seeking a specified class of correction.

It is not a truth guarantee and it is not global adequacy.

## 5. Mini 005 — reopening and contract non-appropriation

### Closure gravity

A valid in-scope counterexample after an authorized closure should reopen the closure, while nuisance/out-of-scope events should not cause indiscriminate panic.

Controllers separated:

```text
typed reopenable  -> reopens valid in-scope counterexample only
rigid              -> retains closure after valid counterexample
panic              -> reopens on everything
```

Earned distinction:

```text
reopenability != reactivity
```

### Contract laundering

A self-rewriter silently reduced the external closure threshold from `q=9` to `q=4`.

It saved challenge cost while every early STOP was unauthorized under the declared contract.

Earned distinction:

```text
optimize policy within contract != optimize the contract itself
```

## 6. Mini 006 — evidence changes a future closure mechanism

M6 introduced a deliberate policy bug: an uncontracted new scope inherited an old closure contract.

Externally typed policy-level evidence caused:

```text
counterexample
-> reopen current claim
-> K0 -> K1
-> future uncontracted scopes DEFER
```

The correction persisted under subsequent throughput-optimization pressure because an independent grounding probe vetoed mutations that would reintroduce unauthorized scope inheritance.

Earned causal arrow:

```text
E* -> Delta K_closure -> Delta pi_future
```

Claim ceiling:

- one demonstrated meta-adaptive correction;
- object-vs-policy failure typing still came from the harness;
- no arbitrary recursive self-improvement claim.

## 7. Correctable Lineage attack — report count is not corrective independence

A hostile audit secretly collapsed nominally distinct reports onto fewer upstream corrective paths.

With nine truly independent paths, false closure was low on the constructed family. With one upstream generator masquerading as nine reports, false closure rose sharply.

Core result:

```text
9 observations != 9 sources
9 sources != 9 independent corrective paths
9 independent paths != globally sufficient evidence
```

The first repair belongs in the measurement/closure assay, not automatically in Mini:

```text
q_effective = number of independent corrective source groups
```

No lineage-graph primitive was promoted.

## 8. Cerebro attack — acquisition policy participates in warrant

M4's closure contract assumed one challenge protocol.

An M2-style active selector changed the acquisition distribution while the closure layer continued to treat the resulting clean reports as if they came from the original protocol.

Core result:

```text
acquisition policy -> evidence opportunity -> warrant
```

and:

```text
component validity != composition validity
```

Retrospective side:

```text
mechanism correction != standing reconciliation
```

Repairing a future policy does not automatically reconsider descendants created under the invalid old mechanism.

## 9. SSI attack — epistemic role and applicability

### Prediction laundering

Mini's native carrier could admit a correct self-prediction through the same observation mechanism as world data.

Core result:

```text
correct prediction != new observation
```

A true datum can have zero incremental empirical authority.

### Applicability laundering

A closure authorized under one regime was transported into a new regime where the model's applicability no longer held.

Core result:

```text
authority != applicability
```

## 10. Reliable-generalization precursor R1

R1 gave the controller two opaque transfer hypotheses that were exactly observationally equivalent on the initial history.

There were eight future contexts, two of which separated the hypotheses.

With a one-probe budget:

```text
passive                     0.00% resolved
random                     25.12% resolved
transfer-discriminating   100.00% resolved
```

Across 10,000 worlds the transfer-aware controller selected a diagnostic context and resolved the correct transfer hypothesis in every case.

Narrow earned result:

> uncertainty over transfer structure can drive active evidence acquisition.

Not earned:

- autonomous transfer-hypothesis invention;
- autonomous discovery of the probing strategy;
- arbitrary invariance discovery;
- reliable generalization generally.

## 11. Nano V0 isolated kernel

Nano was frozen conceptually as:

```text
transition typechecker + append-only journal
```

The first implementation failed twice.

### Failure 1

```text
lineage recorded != lineage causally governing authority
```

A descendant could remain effective after the license that warranted its parent was revoked.

### Failure 2

The first repair over-propagated authority through preservation ancestry:

```text
preservation dependency != warrant dependency
```

The final V0 separated:

- historical lineage;
- warrant-parent liveness;
- preservation obligation.

Final isolated matrix:

```text
Overreach       0 / 60,000
False refusal   0 / 60,000
Invariant fails 0
```

## 12. Mini × Nano Composition V0

Frozen wounded Mini and frozen Nano were composed without modifying either component.

The same proposed transitions were sent to naive persistence and Nano.

Final constructed suite:

```text
illegal attempts accepted by naive persistence  50,000 / 50,000
illegal attempts accepted by Nano                     0 / 50,000
matched legitimate transitions accepted          60,000 / 60,000
native Mini lifecycle control                     10,000 / 10,000
```

This is the first result where the kernel changed persistent authority outcomes without changing the cognition that generated the proposal.

Claim ceiling remains narrow: the contracts were externally supplied and the suite is constructed.

## 13. Current experimental status

The current high-level ladder is descriptive, not a formal maturity scale:

```text
M1  model revision
M2  active epistemic intervention
M3  support != closure permission
M4  contract-scoped budgeted closure
M5  authorized reopening
M6  evidence revises a future closure mechanism
R1  active discrimination of competing transfer hypotheses
N0  semantically agnostic transition enforcement on frozen matrix
C0  wounded Mini proposals behind Nano persistence boundary
```

The next useful experiment should be selected because it discriminates competing explanations, not because it extends the ladder aesthetically.
