# OpenCore

> **Current frontier:** failure attribution under endogenous evidence exposure.

OpenCore studies a narrow question:

> **When memory changes what a learner gets to observe, can it distinguish “my current answer is failing” from “my way of learning is failing”?**

The active branch preserves earlier frozen experiments, but the current living synthesis is intentionally compact. Frozen assay/spec/result artifacts remain authoritative over summaries.

## Canonical compact model

```text
1. Preserve alternatives before authority.
2. Preserve causal boundaries before attribution.
3. Preserve independent, discriminating routes by which evidence can overturn confidence.
```

The unresolved operator is:

```text
observed failure
-> identifying evidence
-> failure attribution
-> method reliance
```

The key separation is:

```text
bad outcome
!=
bad method
```

and the new exposure/identifiability hierarchy is:

```text
evidence availability
!=
diagnostic information
!=
warranted attribution
```

Canonical living boundary: [`crank/RESEARCH_FREEZE.md`](crank/RESEARCH_FREEZE.md).
