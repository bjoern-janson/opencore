# OpenCore

> Toward a universal adaptive transaction kernel for persistent, reopenable cognitive structure.

| Field | Status |
| --- | --- |
| Research object | Candidate universal adaptive transaction kernel |
| Epistemic status | Candidate experimental substrate |
| Phase | Pre-code prospective specification |
| Implementation | None |
| Experiment execution | Not started; no results recorded |
| External authority | None over CEA, FCD/OCC, CCA/CARS, Issue #44, or ARC3 |

OpenCore tests whether a small inspectable computational substrate can turn
experience into authorized, scoped, persistent, reusable, and reopenable state.
It does **not** currently claim to be a universal learner, a cognitive
architecture, an implementation of CEA, or evidence for FCD/OCC.

The first research target is intentionally narrower:

> Can experience become persistent adaptive structure without becoming an
> unchallengeable fact?

“Universal” is the transfer hypothesis under investigation, not the project's
current empirical status.

## Frozen pre-code artifacts

- [CHARTER.md](CHARTER.md) defines the project's scope, authority ceiling, and
  evidence discipline.
- [KERNEL_CONTRACT.md](KERNEL_CONTRACT.md) defines the typed transaction and
  trust boundaries that an implementation must realize.
- [EXPERIMENT_001.md](EXPERIMENT_001.md) preregisters the first causal assay and
  its allowed interpretations.

The first commit containing this complete artifact set is its prospective K0
freeze anchor. Later implementation and results must be descendants; they may
not rewrite the attacked specification in place.
